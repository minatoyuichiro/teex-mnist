# TE-EX MNIST

Code and numerical results for the paper:

> **Hardware-Efficient Exchange-Only QML: Singlet-Triplet Spin Chains via
> Inter-pair Coupling without Magnetic Gradients**
> Yuichiro Minato (blueqat Inc.)
> [arXiv:2608.29017](https://arxiv.org/abs/2608.29017)

The Time-Encoded Exchange (TE-EX) protocol classifies MNIST digits with a
6-spin Heisenberg chain controlled solely by exchange pulses — no magnetic
field gradients. Data-dependent pulse areas of every exchange link are trained
end-to-end together with a small classical head.

## Results reproduced by this code

| Model (identical PCA-12 input, optimizer, budget) | Test acc. (%) |
|---|---|
| Logistic regression on PCA-12 (linear) | 83.21 |
| Classical MLP head on PCA-12 | 91.26 |
| TE-EX, frozen random pulses + MLP head | 52.97 |
| TE-EX, trained pulses + linear readout | 88.08 |
| **TE-EX, trained pulses + MLP head (full)** | **90.89** |

Stability over 5 seeds: 90.99% ± 0.24%. Robustness (trained model, test-time
noise): 89.9% under 10% quasi-static pulse-area noise; 89.8% with 10³
measurement shots per observable. Singlet-product initial-state ablation:
86.96% (dynamics confined to the 5-dimensional S_tot = 0 block).
Batch-Normalization ablation (paper config, no BN in the head): 89.05%.

All accuracies are on the full 10,000-image MNIST test set.

**Hyperparameter selection on a validation split** (`validation_selection.py`,
added for v3): the paper configuration (PCA-12, 6 layers, γ = 0.3) was fixed
in preliminary runs without a validation split. A post-hoc grid search
(PCA dim ∈ {8, 12, 16} × layers ∈ {4, 6, 8} × γ ∈ {0.1, 0.3, 0.6}; 50k/10k
split of the training set, PCA fit on the 50k only) ranks the paper
configuration 13th of 27 on validation (90.24%). The validation-best
configuration (PCA-16, 8 layers, γ = 0.6; val 92.66%), retrained on the full
60k training set, reaches **93.25%** on the test set. All 27 validation
scores are in `results/results.json` (`G_validation_selection`).

## Which observables are needed? (`readout_ablation.py`)

The 11 features are read out by two different primitives: the six ⟨S_z,i⟩ need
energy-selective spin-to-charge conversion, while the five correlators
c = ⟨h⟩ = 4⟨S·S⟩ = 1 − 4⟨P_S⟩ are singlet-probability measurements accessible by
Pauli spin blockade. Retraining with the head restricted to one group (5 seeds):

| Readout | Features | Test acc. (%) |
|---|---|---|
| **Pauli spin blockade only (pair correlators)** | 5 | **89.44 ± 0.45** |
| ⟨S_z,i⟩ only (single-spin readout) | 6 | 87.11 ± 0.60 |
| All (control, same protocol) | 11 | 90.54 ± 0.21 |

The singlet-probability channel alone costs about one point, so the protocol runs
with Pauli spin blockade as its only readout channel. (The 11-feature control is
90.54% rather than 90.89% because the head is built after the model here, which
shifts the RNG draw order; the three arms are comparable with each other.)

## What does the spin chain contribute? (`classical_controls.py`)

The encoder is already non-linear before the chain is reached: the 30 pulse areas
are γ·tanh(b + w·x), parameterized by 360 + 30 = 390 numbers, and the linear-readout
model has 532 trainable parameters in total.

Classical tanh networks, same optimizer and budget (5 seeds):

| Hidden width | Params | Test acc. (%) |
|---|---|---|
| 12 → 10, no tanh | 154 | 81.44 ± 0.16 |
| 20 | 510 | 86.48 ± 0.27 |
| 30 | 760 | 88.39 ± 0.34 |

Keeping the encoder and the readout identical and replacing **only the chain** by a
fixed, untrained map 30 → 11 (532 parameters in every arm, 5 random maps × 3 seeds):

| 30 → 11 map | Test acc. (%) |
|---|---|
| Spin chain (TE-EX, 11 observables) | 88.08 |
| Fixed random linear map | 88.54 ± 0.47 |
| **Fixed random quadratic form θᵀMθ** | **90.15 ± 0.26** |

A fixed quadratic form of the same algebraic type as ⟨ψ|O|ψ⟩ — with no dynamics
behind it — outperforms the chain. The non-linearity that lifts the model above the
linear baseline comes from the tanh encoding, not from the exchange dynamics; what
the chain contributes is that the map is executed by native, all-electrical hardware
under constraints (unitarity, conservation of M_z and S_tot, bounded observables,
limited depth) that a random quadratic form does not have to respect.

## Reachable transformations (`dla_dimension.py`, `ansatz_expressivity.py`)

Exchange conserves M_z and S_tot, so the 20-dimensional M_z = 0 sector splits into
S_tot blocks of dimensions 5 + 9 + 5 + 1 and the reachable group is at most
SU(5) × SU(9) × SU(5) × U(1), of real dimension 24 + 80 + 24 + 1 = **129**. Closing
the algebra generated by {h₁₂, …, h₅₆} under commutators terminates at exactly 129,
block diagonal in the S_tot basis to 9·10⁻⁸: the exchange generators alone span the
whole symmetry-allowed algebra.

A depth-L ansatz has only 5L parameters. Compiling a target that acts as a random
SU(5) on the S_tot = 0 block and as the identity elsewhere, the best achievable
F = |Tr(V†U)|/20 is:

| L | Params | F (free) | F (&#124;θ&#124; ≤ 0.3) |
|---|---|---|---|
| 6 (paper config) | 30 | 0.796 | 0.779 |
| 13 | 65 | 0.927 | 0.836 |
| 26 | 130 | 0.998 | 0.964 |

The ansatz becomes expressive essentially once 5L exceeds 129. The depth used in the
paper is far from that point — a property of the ansatz, not a requirement of the task.

Expressivity is monotone in L (a deeper ansatz contains a shallower one by setting the
extra angles to zero), so the slightly lower fidelities returned at L = 40 and L = 60
(≈0.99, in `results.json`) are an artefact of the optimization at fixed restart and step
budget, not a loss of expressivity.

## Reproduce

```bash
pip install -r requirements.txt
cd code
python test_equiv.py        # exactness check vs. reference implementation (<1e-10)
python run_all.py           # full experiment suite + figures (~4 min on CPU)
python noise_eval.py        # robustness: pulse noise + finite shots (needs run_all first)
python singlet_ablation.py  # initial-state ablation
python bn_ablation.py       # head without Batch Normalization (89.05%)
python validation_selection.py  # 27-config grid on a validation split, then one test eval (~8 min)
python readout_ablation.py      # PSB-only vs single-spin-only readout (5 seeds)
python classical_controls.py    # classical tanh controls + fixed-random-map controls
python dla_dimension.py         # dynamical Lie algebra closes at 129
python ansatz_expressivity.py   # random-SU(5) compilation fidelity vs depth (slow)
```

Outputs are written to `results/` (`results.json` and `figures/`). The
committed `results/` directory contains the exact run used in the paper.
`run_all.py` rewrites `results.json` from scratch, while every other script
appends its own key — so after re-running `run_all.py`, the appending scripts
have to be re-run as well to restore the full file.
`code/mnist.npz` is the standard MNIST dataset (LeCun et al.) in NumPy format,
included for one-command reproduction.

## Implementation note

`eo_core.py` propagates the whole batch at once and replaces `expm` per pulse
with a precomputed eigendecomposition of each link generator
(h = XX + YY + ZZ = 4 S·S) — exact, no approximation. Numerical equivalence
with a verbatim reference implementation is enforced by `test_equiv.py`
(state error < 1e-10, gradients match to machine precision).
